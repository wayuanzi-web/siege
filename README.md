# 千砲破城

兩座城樓隔著戰場輪流開砲的物理攻城遊戲，做成可安裝的網頁 App（PWA）。不需要帳號，手機橫拿、點開就能玩。

**線上遊玩：<https://wayuanzi-web.github.io/siege/>**

傳給 LINE 上的朋友時，網址後面加 `?openExternalBrowser=1`（<https://wayuanzi-web.github.io/siege/?openExternalBrowser=1>），連結會用手機的瀏覽器開啟（LINE 內建瀏覽器不能安裝到主畫面）。主畫面的「分享」按鈕會自動加上。

## 怎麼玩

- 雙方**輪流**開火：輪到你的時候，在戰場上拖曳調整仰角和力道（虛線是預估的彈道，已經把風算進去），放開就發射。**全隊打同一個落點**：帶頭的兵照你瞄的角度打，其他兵各自算一個打得到同一點的角度（先碰到機關的，就瞄那個機關），一輪砲火集中在一起。打完換敵軍。
- **城破才是勝負**：畫面上方的城防條是城樓還站著多少（照每一塊磚的大小算，打裂了的少算一點）。把敵城打塌到城防條歸零，帥旗倒下，就贏了；你的城塌了就輸。把對面的兵全部打倒也算贏。快見底的城每回合會自己再塌一點（「搖搖欲墜」），拖太久（大多是第 10 回合起）雙方的城都會開始塌，不會停在兩邊殘兵互射的局面。
- 每一座城都分好幾段，**一段一段垮**：前面的樓、後面的主樓、吊著的殿、船身……每一段有自己的垮法，主要靠那一關的機關（火藥桶、滾石、雪崩、引信、浮空晶石、船艙進水、石碑骨牌、鐵鍊、吊籠、共鳴晶柱、大鐘），一輪打不完。
- 每一關戰場中間都有一個那一關自己的**放大機關**：第一關和魔王城是倍增符（穿過去一發變多發），其他關是滾地砲、冰鏡、地火、噴流、打水漂、骨牌、雷雲、彈簧板、稜鏡、大鐘共振。瞄準的虛線會照真的物理轉彎（彈過冰鏡、被噴流捲走、在海面上跳），照著它打就好。雙方都能用，敵軍也會用。戰場正中間有打不壞的地形（小山、岩石），被轟到地上的兵沒辦法平平地對射，要吊高越過去。
- 城是一塊一塊的磚、木頭、冰和鐵疊起來的，全部照物理算：打斷柱子，上面的樓板、屋頂和兵會跟著垮下來。**被轟出城的兵不會死**：站在哪裡就從哪裡接著打（掉下深淵、掉進海裡、被沖走、飛出戰場才算出局）；摔下來、被碎磚砸到很痛，但一下最多扣四成血（滾石、大鐘、石碑、雪崩這種大傢伙正面砸到還是會死）。
- 一輪垮得越多，**連珠**集氣越快；集滿按右下角的金色按鈕，這一輪每個兵連打三次。**護罩**在敵軍開火前按，可以擋下他們一整輪，也能讓被凍住的兵立刻解凍。
- 打到兵、打到城會跳出**傷害數字**（打到敵兵是白字，自己的兵挨打是紅字，黃色大字是暴擊，打到城是土黃色的小字）；打中被剋制的材質會跳「火剋木」「雷剋鐵」「酸剋石」這類字，那一下特別痛。
- 過關看城防剩多少給一到三顆星（三顆星：一個兵都沒倒、城防條剩一半以上），拿金幣在「強化」升級火力、準星、城防、護罩、連珠。「設定」可以調難度（輕鬆／標準／硬仗）、音效、震動。
- 電腦上也能用鍵盤：方向鍵或 W／A／S／D 調仰角和力道，空白鍵或 Enter 發射，Z 護罩，X 連珠，P 或 Esc 暫停。

**共通的規則**

- **超載**：開場時量好每根柱子、每塊樓板撐著多重。旁邊那根斷了、重量全壓過來，超過它撐得住的就嘎吱作響、掉灰、裂開，撐不了多久也斷——一根接一根的連鎖坍塌。
- **榫接**：吊著的殿、五重塔這種整間的木構，磚和磚之間用榫頭接死，被打會整間晃、整間歪；要把那一塊打碎（或打到快碎），榫頭才斷。
- **繩索與鐵鍊**：麻繩幾箭就斷、火燒得斷；鐵鍊要轟天砲或投石兵的大石頭才打得快，雷也行，火箭、箭打不太動。被扯得太緊也會繃斷。
- **開場護符（雙方一樣）**：第一回合，每一邊挨的第一輪砲火，兵只受幾成傷、不會被凍住電暈或壓扁；被轟出城、掉下深淵、掉進水裡都會被送回城上（原位也垮了就放到城後面站得穩的地方）；第一輪留下來的火、引信、還在垮的樓，到自己打完下一輪之前也弄不死兵。城樓和機關照常打得壞（第一輪就打得出坍塌，但城破要好幾段一起垮）。
- **逆轉集氣**：兵比對面少、或城樓比對面塌得多的時候，打出的傷害和坍塌讓連珠集氣快五成（連珠按鈕上會掛「逆轉」）。

| 兵種 | 打法 |
| --- | --- |
| 火箭兵 | 一輪兩發火箭，基本火力 |
| 連弩手 | 一輪連射六箭，打木頭、打兵都快 |
| 轟天砲 | 一輪一發，一炸一大片，石牆也扛不住；身子骨比較單薄 |
| 火油兵 | 木頭和屋瓦一點就著，還會延燒；冰一烤就化 |
| 冰術士 | 炸到的敵兵凍住、下一輪不能開火，磚也變脆 |
| 雷法師 | 落點引一道雷從天上劈下來，專打屋頂和鐵甲 |
| 防空弩 | 每一輪把飛過來的砲彈射下三發 |
| 氣球兵 | 放轟炸氣球：先飄到半路，下一輪飛到你頭上丟炸彈 |
| 投石兵 | 丟一顆真的大石頭：不會爆，但會一路撞、一路滾，撞斷柱子、推倒石碑最拿手 |

## 第三篇與演武場

第三篇（第十三到十八關，還在做）每邊**六個兵**，多三條規則；九種新兵器先放在演武場試打。

**第三篇的規則**

- **誤傷**：自己的砲炸到自己人一樣會傷（八成）。敵軍瞄準時也會避開自己的兵。
- **弱點暴擊 ×2**：正中繩子和鐵鍊綁住的地方、榫頭、共鳴晶柱、五重塔的心柱、魔晶，或打中兵的頭，傷害加倍，跳黃色的大字。
- **屬性剋制**：火剋木（燒瓦、化冰）、雷剋鐵、酸剋石（也蝕鐵）、風掀瓦折竹、磁吸鐵；冰炸到正在燒的磚會把火撲滅。剋制的倍率每一關本來就有，第三篇多了冰能滅火。

**九種新兵**

| 兵種 | 打法 |
| --- | --- |
| 鏈彈手 | 兩顆鐵球連著鐵鍊轉著飛：專斷繩索和細柱子（打斷了還會繼續往前），打到兵會把他纏住、下一輪不能開火 |
| 鑽地手 | 鑽頭彈鑽穿兩三塊磚，鑽到裡面才炸開：專打厚牆和地窖 |
| 子母砲手 | 砲彈飛到最高點分成六顆小炸彈，灑下一大片 |
| 爆破兵 | 黏性炸藥黏在打到的牆上，等你下一輪開火時才爆，威力最大；對方打得掉它、工兵拆得掉它 |
| 磁暴師 | 落點放出磁暴，把附近的鐵磚、鐵鍊、吊籠一把吸過去：鐵造的城最怕他 |
| 風術士 | 落點捲起一道龍捲風：輕的木頭、屋瓦和站在外面的兵都會被捲起來甩出去 |
| 酸液兵 | 酸液沾到的磚和兵一直被蝕好幾秒，石牆、鐵甲最怕 |
| 狙擊手 | 又平又快的一發，不太受重力影響，穿得過一層木牆，專打兵（打中頭是暴擊） |
| 工兵 | 不攻擊：每一輪修好自己城上兩塊打裂的磚、拆掉黏在城上的炸藥；城都好好的，就在城前架一道木牆（最多兩道，自己的砲穿得過去） |

**演武場**（第三篇分頁裡，一直都能進）：十八種兵任你挑，每邊最多六個（點主畫面上的頭像換人，「敵軍隨機」一鍵換敵方的兵）；戰場可以選演武城（為六個兵蓋的城：主樓有木頂、石牆、鐵牆，裡面吊著一盞鐵燈；旁邊的木塔腳下夾著火藥桶，每一種兵器的剋制都試得到），或第一到十一關的城、地形和中間的機關（魔王城不能選）；誤傷可以開關，暴擊和冰能滅火一直開著。試打不給星星、不給金幣、不解鎖關卡。

## 修改與上線

```
python3 src/build.py https://wayuanzi-web.github.io/siege/    # 重新產生 index.html、sw.js、manifest
git add -A && git commit -m "..." && git push
```

GitHub Pages 從 `main` 分支根目錄發布，推上去約一分鐘後生效。每次建置會換一個離線快取名稱，玩家下次連線開啟就會拿到新版。

不帶網址執行 `python3 src/build.py` 只會產生 `src/dist/`：`qianpao.html` 是 Claude Artifact 用的頁面片段，`index.html` 是本機測試用的完整頁面。

## 調整難度與測試

- 關卡資料在 `src/parts/60-levels.js`：`foe.hp`／`foe.dmg`（敵軍耐久、火力倍率）、`foe.ai.err`（敵軍手抖的程度）、`objs`（冰鏡、噴流、雷雲、彈簧板、稜鏡、黑洞）、`roll`（滾地）、`skip`（打水漂）、`gates`（倍增符，只有第一關和魔王城）、`boss`（魔王的階段、回血）、`wind`、`rocks`、`fall`（城防條在完整度多少時歸零，預設三成）、`blockHp`（城樓磚的耐久倍率，預設 2 倍）、`sudden`（第幾回合起雙方的城開始自己塌）、`extra`（中場打不壞的岩石，藍圖也在 40-defs）、`rules`（第三篇的規則：`ff` 誤傷、`crit` 弱點暴擊、`elem` 冰能滅火）等。新兵器的數字在 `40-defs.js` 的 `WL`（`chain`、`drill`、`split`、`stick`、`mag`、`tw`、`acid` 各自的參數；`ai` 是敵軍估這種兵器打一發值多少），誤傷、暴擊的倍率 `FF_K`、`CRIT_K` 在 `51-arms.js`。城樓藍圖在 `src/parts/40-defs.js`（每一格一個字元；`wts` 是各材質算進完整度的比重，`weld` 是榫接的範圍）。城破的算法（`FALL_TH`、`STAND_K`、`CASTLE_HP`、`CRUMBLE`）和難度三檔的倍率 `DIFFS` 在 `src/parts/50-sim.js`。
- Node 的測試只載模擬的部分，不開瀏覽器：
  - `node test/table.js [場數] [強化等級] [難度] [關卡範圍，例 7-12]`：各關 × 三種自動玩家（新手／普通／很會玩）的勝率（其中幾場是打塌敵城）、回合數、損兵（`BOTS=newbie,casual` 只跑其中幾種，`J=2` 同時跑幾個）。`node test/why.js <關卡> [自動玩家] [場數]`：每一場哪一邊輸、輸在城破還是守軍全倒，雙方誰倒了、怎麼倒的。
  - `node test/first.js <關卡>`：開場公平性，敵軍先打一輪、我方不還手，看我方倒幾個兵（應該是 0：開場護符雙方一樣，各自第一次挨打時兵不會倒、不會被炸出城）。關卡寫 `p0`–`p11` 是演武場的戰場（`FOE=chain,cluster,…` 指定敵軍的兵），看新兵器第一輪會不會就打死人、打塌城。`node test/r1probe.js <關卡>`：同樣的情況，列出敵軍第一輪動到了我方哪些機關（護符不護機關，雙方一樣，所以這裡會有東西；拿來看第一輪能不能就把一座城打垮）。
  - `node test/log.js <關卡> [自動玩家] [seed]`：跑一場，印出每一回合誰倒了、機關動了什麼。`node test/mech.js <關卡> <0|1> "cut:stay; kill:3,5; pop:0; hull:bow; fuse; stake; bell"`：直接對某一邊的機關動手，看兩邊垮法是不是一樣。
  - `node test/arms.js [場數] [戰場 0–11]`：演武場用新兵器的各種組合打完整場，看會不會出錯、卡住，順便數鏈彈纏人、鑽頭、黏炸藥、龍捲風、暴擊這些事件各發生幾次。`node test/range.js [場數] [戰場] [輪數]`：靶場，我方六個同一種兵、敵軍不還手，打幾輪之後敵城、敵兵各掉多少（`ONLY=chain,drill` 只比其中幾種），拿來比十八種兵器的火力。
  - `node test/stab.js`：每一張城樓藍圖（含演武城）疊起來穩不穩。`node test/where.js <關卡>`：敵城每一塊磚、每條繩子的座標；`node test/poke.js <關卡> "bomb@x,y ; …"` 在指定位置引爆，看機關有沒有照設計垮（`test/pokefilm.py` 同樣的寫法在瀏覽器裡連拍，`test/seedfilm.py` 重播某一場自動玩家的對局）。`node test/inv.js`：各關各種自動玩家打完，檢查內部數字和卡死。
  - `node test/rigs.js`：兵站不住時的規則（懸空、跨在縫上、疊在一起）的最小場景。`node test/onhead.js`、`node test/tiptoe.js`：輪到人瞄準時，有幾個兵頭上靠著磚、只靠腳尖站著。
  - 環境變數 `SIEGE_SRC=<另一份 src/parts>` 可以拿兩個版本比。
- 瀏覽器測試（需要 playwright）：`test/rsoak.py` 走真的畫面迴圈快轉打完每一關（`--monkey` 改成亂按），`test/shot.py <關卡> <秒數>` 截圖（`test/allshots.py 1-12 <秒數> <標籤>` 每關一張拼成一張大圖），`test/ui.py` 各畫面版面，`test/touch.py` 直拿橫拿的觸控，`test/perf.py` 效能。
- `bash test/lint.sh`：ESLint 檢查沒宣告的名稱。

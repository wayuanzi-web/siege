# 千砲破城

兩座城樓隔著戰場輪流開砲的物理攻城遊戲，做成可安裝的網頁 App（PWA）。不需要帳號，手機橫拿、點開就能玩。

**線上遊玩：<https://wayuanzi-web.github.io/siege/>**

傳給 LINE 上的朋友時，網址後面加 `?openExternalBrowser=1`（<https://wayuanzi-web.github.io/siege/?openExternalBrowser=1>），連結會用手機的瀏覽器開啟（LINE 內建瀏覽器不能安裝到主畫面）。主畫面的「分享」按鈕會自動加上。

## 怎麼玩

- 雙方**輪流**開火：輪到你的時候，在戰場上拖曳調整仰角和力道（虛線是預估的彈道，已經把風算進去），放開就發射；城裡每個兵各打一輪。打完換敵軍。
- 砲彈穿過藍色的**倍增符**（×2、×3…）會一發變多發，連續穿過好幾道就是滿天的砲彈。紅色的赤符是敵軍的，會擋你的砲彈、讓他們的砲彈變多，可以打掉。
- 城是一塊一塊的磚、木頭、冰和鐵疊起來的，全部照物理算：打斷柱子，上面的樓板、屋頂和兵會跟著垮下來；打穿樓板，站在上面的兵會掉下去；歪掉的塔會滑、會倒，一塊撞一塊地連鎖坍塌。掉下來的東西砸到兵、兵摔下樓、被轟出城外，都會倒。
- 把敵方的兵全部打倒就贏（魔王城要打倒魔王）。一輪垮得越多，**連珠**集氣越快；集滿按右下角的金色按鈕，這一輪每個兵連打三次。**護罩**在敵軍開火前按，可以擋下他們一整輪，也能讓被凍住的兵立刻解凍。
- 過關拿金幣，在「強化」升級火力、準星、城防、護罩、連珠。「設定」可以調難度（輕鬆／標準／硬仗）、音效、震動。
- 電腦上也能用鍵盤：方向鍵或 W／A／S／D 調仰角和力道，空白鍵或 Enter 發射，Z 護罩，X 連珠，P 或 Esc 暫停。

## 檔案

| 路徑 | 內容 |
| --- | --- |
| `index.html` `sw.js` `manifest.webmanifest` | 上線的網頁 App，由建置腳本產生，不要直接改 |
| `icon-*.png` `apple-touch-icon.png` `og.png` | App 圖示與連結預覽圖 |
| `src/parts/` | 遊戲原始碼，依檔名順序串接。`40-defs` 材質、兵種、城樓藍圖；`45-phys` 物理（磚塊斷裂、碎塊、兵的身體）；`50-sim` 回合與規則；`52-ai` 敵軍瞄準；`60-levels` 關卡資料；`65-bot` 測試用的自動玩家；`70-render`／`55-fx` 畫面與特效；`80-ui`／`85-main` 介面與操作 |
| `src/vendor/` | 物理引擎 [planck.js](https://github.com/piqnt/planck.js) v1.5.0 與它的 MIT 授權書（建置時原封不動放進頁面） |
| `src/webparts/` | 網頁 App 專用：分享與安裝按鈕、離線快取、manifest |
| `src/build.py` | 建置腳本 |
| `src/gen_icons.py` | 重新產生圖示與預覽圖（需要 playwright、pillow） |
| `test/` | 自動玩家與測試，見下 |

## 修改與上線

```
python3 src/build.py https://wayuanzi-web.github.io/siege/    # 重新產生 index.html、sw.js、manifest
git add -A && git commit -m "..." && git push
```

GitHub Pages 從 `main` 分支根目錄發布，推上去約一分鐘後生效。每次建置會換一個離線快取名稱，玩家下次連線開啟就會拿到新版。

不帶網址執行 `python3 src/build.py` 只會產生 `src/dist/`：`qianpao.html` 是 Claude Artifact 用的頁面片段，`index.html` 是本機測試用的完整頁面。

## 調整難度與測試

- 關卡資料在 `src/parts/60-levels.js`：`foe.hp`／`foe.dmg`（敵軍耐久、火力倍率）、`foe.ai.err`（敵軍手抖的程度）、`gates`（倍增符）、`wind`、`rocks` 等。城樓藍圖在 `src/parts/40-defs.js`（每一格一個字元）。難度三檔的倍率在 `src/parts/50-sim.js` 的 `DIFFS`。
- Node 的測試只載模擬的部分，不開瀏覽器：
  - `node test/table.js [場數]`：六關 × 三種自動玩家（新手／普通／很會玩）的勝率、回合數、損兵。
  - `node test/first.js <關卡>`：開場公平性，敵軍先打一輪、我方不還手，看我方倒幾個兵（應該是 0）。
  - `node test/stab.js`：每一張城樓藍圖疊起來穩不穩。`node test/inv.js`：各關各種自動玩家打完，檢查內部數字和卡死。
  - `node test/rigs.js`：兵站不住時的規則（懸空、跨在縫上、疊在一起）的最小場景。`node test/onhead.js`、`node test/tiptoe.js`：輪到人瞄準時，有幾個兵頭上靠著磚、只靠腳尖站著。
  - 環境變數 `SIEGE_SRC=<另一份 src/parts>` 可以拿兩個版本比。
- 瀏覽器測試（需要 playwright）：`test/rsoak.py` 走真的畫面迴圈快轉打完每一關（`--monkey` 改成亂按），`test/shot.py <關卡> <秒數>` 截圖，`test/ui.py` 各畫面版面，`test/touch.py` 直拿橫拿的觸控，`test/perf.py` 效能。
- `bash test/lint.sh`：ESLint 檢查沒宣告的名稱。

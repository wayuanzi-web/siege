# 千砲破城

兩座城樓隔著戰場輪流開砲的物理攻城遊戲，做成可安裝的網頁 App（PWA）。不需要帳號，手機橫拿、點開就能玩。

**線上遊玩：<https://wayuanzi-web.github.io/siege/>**

傳給 LINE 上的朋友時，網址後面加 `?openExternalBrowser=1`（<https://wayuanzi-web.github.io/siege/?openExternalBrowser=1>），連結會用手機的瀏覽器開啟（LINE 內建瀏覽器不能安裝到主畫面）。主畫面的「分享」按鈕會自動加上。

## 怎麼玩

- 雙方**輪流**開火：輪到你的時候，在戰場上拖曳調整仰角和力道（虛線是預估的彈道，已經把風算進去），放開就發射；城裡每個兵各打一輪。打完換敵軍。
- 每一關戰場中間都有一個那一關自己的**放大機關**：第一關和魔王城是倍增符（穿過去一發變多發），其他關是滾地砲、冰鏡、地火、噴流、打水漂、骨牌、雷雲、彈簧板、稜鏡、大鐘共振。瞄準的虛線會照真的物理轉彎（彈過冰鏡、被噴流捲走、在海面上跳），照著它打就好。雙方都能用，敵軍也會用。
- 城是一塊一塊的磚、木頭、冰和鐵疊起來的，全部照物理算：打斷柱子，上面的樓板、屋頂和兵會跟著垮下來；打穿樓板，站在上面的兵會掉下去；歪掉的塔會滑、會倒，一塊撞一塊地連鎖坍塌。掉下來的東西砸到兵、兵摔下樓、被轟出城外，都會倒。
- 把敵方的兵全部打倒就贏（最後一關魔王城要打倒魔王）。一輪垮得越多，**連珠**集氣越快；集滿按右下角的金色按鈕，這一輪每個兵連打三次。**護罩**在敵軍開火前按，可以擋下他們一整輪，也能讓被凍住的兵立刻解凍。
- 過關拿金幣，在「強化」升級火力、準星、城防、護罩、連珠。「設定」可以調難度（輕鬆／標準／硬仗）、音效、震動。
- 電腦上也能用鍵盤：方向鍵或 W／A／S／D 調仰角和力道，空白鍵或 Enter 發射，Z 護罩，X 連珠，P 或 Esc 暫停。

## 十二個關卡

主畫面分兩個分頁（第一篇 1–6 關、第二篇 7–12 關），打下一關開下一關。每一關雙方用**同一座城**（敵城是左右鏡像），各自派自己的兵：對方能怎麼垮你，你就能怎麼垮對方。每座城的下半部都有作用（火藥庫、兵房、浮空晶石、石墩、閘、共鳴晶柱、心柱、魔晶），吊著的東西被打會晃、會撞、會掉。

**共通的規則**

- **超載**：開場時量好每根柱子、每塊樓板撐著多重。旁邊那根斷了、重量全壓過來，超過它撐得住的就嘎吱作響、掉灰、裂開，撐不了多久也斷，重量再往下一根移——一根接一根的連鎖坍塌。
- **繩索與鐵鍊**：麻繩幾箭就斷、火燒得斷；鐵鍊要轟天砲或投石兵的大石頭才打得快，雷也行，火箭、箭打不太動。被扯得太緊也會繃斷。
- **開場護符**：第一回合敵軍還在試射，只瞄你的兵、打到也只算幾成；你這邊的機關（繩子和鐵鍊、吊著的東西、氣球和浮空晶石、船艙、引信和火藥庫、擋滾石的木樁、共鳴晶柱、冰崖的冰棚、會倒向你的石碑、石柱的石墩、避雷針、吊籠的閘、心柱、魔晶、中間的大鐘）它動不了，被轟出城的兵也會被送回原位，不會還沒開打就先垮。
- **逆轉集氣**：兵比對面少的時候，打出的傷害和坍塌讓連珠集氣快五成（連珠按鈕上會掛「逆轉」），一次大坍塌就能翻盤。

| 兵種 | 打法 |
| --- | --- |
| 火箭兵 | 一輪兩發火箭，基本火力 |
| 連弩手 | 一輪連射六箭，打木頭、打兵都快 |
| 轟天砲 | 一輪一發，一炸一大片，石牆也扛不住 |
| 火油兵 | 木頭和屋瓦一點就著，還會延燒；冰一烤就化 |
| 冰術士 | 炸到的敵兵凍住、下一輪不能開火，磚也變脆 |
| 雷法師 | 落點引一道雷從天上劈下來，專打屋頂和鐵甲 |
| 防空弩 | 每一輪把飛過來的砲彈射下三發 |
| 氣球兵 | 放轟炸氣球：先飄到半路，下一輪飛到你頭上丟炸彈 |
| 投石兵 | 丟一顆真的大石頭：不會爆，但會一路撞、一路滾，撞斷柱子、推倒石碑最拿手 |

## 修改與上線

```
python3 src/build.py https://wayuanzi-web.github.io/siege/    # 重新產生 index.html、sw.js、manifest
git add -A && git commit -m "..." && git push
```

GitHub Pages 從 `main` 分支根目錄發布，推上去約一分鐘後生效。每次建置會換一個離線快取名稱，玩家下次連線開啟就會拿到新版。

不帶網址執行 `python3 src/build.py` 只會產生 `src/dist/`：`qianpao.html` 是 Claude Artifact 用的頁面片段，`index.html` 是本機測試用的完整頁面。

## 調整難度與測試

- 關卡資料在 `src/parts/60-levels.js`：`foe.hp`／`foe.dmg`（敵軍耐久、火力倍率）、`foe.ai.err`（敵軍手抖的程度）、`objs`（冰鏡、噴流、雷雲、彈簧板、稜鏡、黑洞）、`roll`（滾地）、`skip`（打水漂）、`gates`（倍增符，只有第一關和魔王城）、`boss`（魔王的階段、回血）、`wind`、`rocks` 等。城樓藍圖在 `src/parts/40-defs.js`（每一格一個字元）。難度三檔的倍率在 `src/parts/50-sim.js` 的 `DIFFS`。
- Node 的測試只載模擬的部分，不開瀏覽器：
  - `node test/table.js [場數] [強化等級] [難度] [關卡範圍，例 7-12]`：各關 × 三種自動玩家（新手／普通／很會玩）的勝率、回合數、損兵（`BOTS=newbie,casual` 只跑其中幾種，`J=2` 同時跑幾個）。`node test/why.js <關卡> [自動玩家] [場數]`：每一場雙方誰倒了、怎麼倒的。
  - `node test/first.js <關卡>`：開場公平性，敵軍先打一輪、我方不還手，看我方倒幾個兵（應該是 0）。`node test/r1probe.js <關卡>`：同樣的情況，看我方的機關有沒有被動到（應該什麼都沒發生）。
  - `node test/log.js <關卡> [自動玩家] [seed]`：跑一場，印出每一回合誰倒了、機關動了什麼。`node test/mech.js <關卡> <0|1> "cut:stay; kill:3,5; pop:0; hull:bow; fuse; stake; bell"`：直接對某一邊的機關動手，看兩邊垮法是不是一樣。
  - `node test/stab.js`：每一張城樓藍圖疊起來穩不穩。`node test/where.js <關卡>`：敵城每一塊磚、每條繩子的座標；`node test/poke.js <關卡> "bomb@x,y ; …"` 在指定位置引爆，看機關有沒有照設計垮（`test/pokefilm.py` 同樣的寫法在瀏覽器裡連拍，`test/seedfilm.py` 重播某一場自動玩家的對局）。`node test/inv.js`：各關各種自動玩家打完，檢查內部數字和卡死。
  - `node test/rigs.js`：兵站不住時的規則（懸空、跨在縫上、疊在一起）的最小場景。`node test/onhead.js`、`node test/tiptoe.js`：輪到人瞄準時，有幾個兵頭上靠著磚、只靠腳尖站著。
  - 環境變數 `SIEGE_SRC=<另一份 src/parts>` 可以拿兩個版本比。
- 瀏覽器測試（需要 playwright）：`test/rsoak.py` 走真的畫面迴圈快轉打完每一關（`--monkey` 改成亂按），`test/shot.py <關卡> <秒數>` 截圖（`test/allshots.py 1-12 <秒數> <標籤>` 每關一張拼成一張大圖），`test/ui.py` 各畫面版面，`test/touch.py` 直拿橫拿的觸控，`test/perf.py` 效能。
- `bash test/lint.sh`：ESLint 檢查沒宣告的名稱。
